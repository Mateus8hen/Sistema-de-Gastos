# Sistema de Controle de Gastos

Um sistema desenvolvido para auxiliar no gerenciamento de gastos pessoais, permitindo o controle de receitas, despesas e acompanhamento financeiro de forma simples e intuitiva.

Status do Projeto: 🚧 Em desenvolvimento

# 📖 Sobre o Projeto

O objetivo deste projeto é oferecer uma plataforma para que o usuário possa registrar suas movimentações financeiras, visualizar relatórios e acompanhar sua situação financeira através de gráficos e indicadores.

Este projeto está sendo desenvolvido com foco em boas práticas de programação, organização de código e aprendizado de desenvolvimento Full Stack.

# 🛠️ Tecnologias
Back-end
* C#
* ASP.NET Core
* Entity Framework Core

Front-end
* HTML5
* CSS3
